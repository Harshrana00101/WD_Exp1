Sequential Git Execution Log
1. Repository Initialization & Identity

Initialize an empty Git repository with main as the primary trunk branch and configure user details.

git init -b main
git config user.name "Harsh Kumar"
git config user.email "harshrana00101@example.com"
2. Staging & Initial Commit

Stage all files from the root repository and commit them to the main branch.

git add .
git commit -m "feat: complete experiments with Bootstrap layouts"
3. Branch Creation & Merging Lifecycle

Create an isolated development branch, apply changes, switch back to main, and merge seamlessly.

# 1. Create and switch to new branch
git checkout -b feature/static-site-deployment

# 2. Make commits on the feature branch
git add .
git commit -m "feat(exp-1): add static showcase page for GitHub Pages"

# 3. Switch back to main and merge
git checkout main
git merge feature/static-site-deployment
4. Connect Remote & Push

Link local git tracking to your GitHub repository and publish the changes.

git remote add origin https://github.com/Harshrana00101/web-development-experiments.git
git push -u origin main
GitHub Pages Steps
  1. Push your code to your GitHub repo: web-development-experiments.
  2. Navigate to Settings > Pages.
  3. Under Source, choose Deploy from a branch.
  4. Under Branch, select main and folder / (root).
  5. Click Save. In 1 minute, your site is hosted live!
